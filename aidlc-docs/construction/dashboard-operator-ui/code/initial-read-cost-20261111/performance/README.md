`production-baseline.json` separates instrumented attribution from uninstrumented
timing. `production-comparison.json` alternates old/new readers in a standalone
process against identical canonical generations. Only hashes/metadata leave Fly.
The candidate is compiled in probe memory and never replaces application files.

`benchmark-*-first.json` retain the first local baseline-then-candidate runs;
un-suffixed reports retain candidate-then-baseline confirmation. The synthetic
fixture is generated by benchmark.py prepare; fixture-manifest.json records its
exact bytes/hashes. Files and models are varied, but this is not a million-event
or native-browser qualification. Local resource.ru_maxrss is macOS bytes, while
the production reports use Linux KiB; both include Python imports and are process
high-water values, not an instantaneous idle-RSS delta.

Scripts run from the repository root and use `.tmp/dashboard-initial-read-20261111`.
To reconstruct the frozen oracle, export Git21142a7's `src/utils/bounded_read.py`
as `bounded_read_baseline.py` in that scratch directory. The probe scripts print
a safely quoted Fly command; executing that command is a separate authorized
read-only operation. No credential or raw runtime row is stored in this evidence.

All 9,000 seeded raw/object comparisons (including exact cooperative checkpoints,
invalid/truncated data and budgets) match. Source/test validation is in
`../validation/`. The original DEBT-083 acceptance thresholds remain unchanged.
