# DEBT-074 signal and selection evidence

`proposals_emitted` remains the cumulative analyze-attempt denominator; its historical meaning never changes. Add counters for attempts observed by the new schema, neutral results, non-neutral results, successfully built candidates and final candidates selected by the public API (after symbol dedup and top-K). Result counters are not mutually exclusive with sizing failures: a non-neutral signal can fail sizing. Selection counters do not assert persistence/opening. Counters are account/technique scoped and version labels remain forensic only.

Neutral-only classification requires complete attempt coverage (new observed attempts equal all emitted attempts), all observed results neutral, no non-neutral/built/selected/failure evidence, no persisted proposals and no malformed evidence. Otherwise absent proposals leave no-signal/selection/history possibilities explicit. An opened proposal remains opened. Legacy absent fields default zero and never manufacture historical signal outcomes; interrupted/persistence-failed stages remain incomplete. Read-only audit output names analyze attempts and all new counters, and points to DEBT-079 deselection evidence instead of asserting a missing-candidate defect.

NFR: retain atomic per-account metric snapshots, increment observed attempts in the same write as the legacy denominator, catch stage-metric OSError without changing proposals, and never alter runtime selection, sizing, gates or persisted proposal final states. Tools remain read-only. New stage snapshots are constant-size; no log-history scan or data migration is added.
