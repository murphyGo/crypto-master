# Presentation / Consumer Contract

Keep existing safety score/band/factor displays and configured paper/live controls.
The shared service may expose evaluation time/availability using its existing
freshness surfaces; do not display storage paths or implementation internals.
Notifications and the runtime pause gate must consume the same approved safety
snapshot, rather than computing conflicting windows for the same decision.
Explicit incomplete state must remain visible; no empty-data SAFE presentation.
No new operator action, exchange command, credential or activation control is added.
